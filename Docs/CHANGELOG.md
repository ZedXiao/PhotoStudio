# 更新日志

**简体中文** | [English](CHANGELOG.en.md) · [项目首页](../README.md)

本日志汇总已有版本说明。各版本链接保留原始实现与验收细节；当前行为以首页和开发指南为准。

## 1.2.7（构建 11）— 2026-11-03

- 应用图标改为浅色底、蓝绿色光圈和暖黄色中心，统一各尺寸的圆角与透明边缘。
- 添加可重复运行的 Release 打包流程，生成 DMG 拖拽安装包、ZIP 和 SHA-256 校验文件。
- 安装包使用临时签名（ad hoc），未使用 Apple Developer ID 签名，未做苹果公证；最低系统和 Apple Silicon 支持范围保持不变。

[发布说明](releases/v1.2.7.md) · [实现与验收记录](PhotoStudio-1.2.7.md) · [图标设计记录](AppIcon-Design.md)

## 1.2.6（构建 10）— 2026-11-03

- 缩略图面板的箭头凸起改为 36 pt 平缓顶部，整体宽 104 pt、高 10 pt。
- 两侧三段三次曲线与面板上沿平顺连接，保留阴影空间和固定尺寸下滑动画。

[原始记录](PhotoStudio-1.2.6.md)

## 1.2.5（构建 9）— 2026-11-03

- 为原生玻璃阴影保留 24 pt 空间，修复圆角外侧的矩形截断与收起残影。
- 扩大箭头点击区域；保留固定预览、胶片条和 220 ms 下滑。

[原始记录](PhotoStudio-1.2.5.md)

## 1.2.4（构建 8）— 2026-11-03

- 大缩略图保持固定尺寸，整块面板以 220 ms ease-out 下滑，逐步露出底部胶片条。
- 支持中途反向切换；主图和缩放位置不参与布局动画，减少动态效果时直接切换。

[原始记录](PhotoStudio-1.2.4.md)

## 1.2.3（构建 7）— 2026-11-03

- 总览改为覆盖式底部面板，保留主预览适应窗口比例和 100% 平移位置。
- 添加面板上沿的一体玻璃箭头凸起，统一总览展开和收起入口。

[原始记录](PhotoStudio-1.2.3.md)

## 1.2.2（构建 6）— 2026-11-03

- 总览与胶片条共用玻璃面板，统一展开／收起路径，减少预览重新插入造成的跳变。
- 统一 Esc、双击与按钮的返回逻辑；总览期间停用主图缩放控件。

[原始记录](PhotoStudio-1.2.2.md)

## 1.2.1（构建 5）

- 目录树使用稳定标识、固定高度的原生侧栏行；加载和失败状态显示在对应行内。
- 删除确认改为当前窗口内的单层玻璃面板，管理焦点、Esc、回车及底层操作禁用。

[原始记录](PhotoStudio-1.2.1.md)

## 1.2.0（构建 4）— 2026-11-02

- 引入按需目录树、每目录独立 RAW 与展开偏好，以及上次浏览子目录恢复。
- 添加大缩略图总览、预览快捷箭头和每次手势最多一张的触控板切图。
- 修复横竖照片居中；记忆 RAW 联动删除偏好；将书签创建移到后台。
- 核心测试增加到 18 项，覆盖目录、偏好、手势及原有解码回归。

[原始记录与交互验收](PhotoStudio-1.2.0.md)

## 1.1.0

- 统一最低系统和所有部署声明为 macOS 26.0，引入原生 Liquid Glass。
- 保留系统窗口、侧栏和工具栏，照片内容不施加玻璃材质。

[原始记录](Liquid-Glass-1.1.0.md)

## 1.0.1

- 将完整 RAW 解码、缩略图与方向读取入口的 LibRaw 实例移到堆上，修复后台线程栈溢出。
- 增加 512 KiB 工作线程回归和 `PhotoStudioProbe --worker`，使样片验证覆盖后台执行环境。
