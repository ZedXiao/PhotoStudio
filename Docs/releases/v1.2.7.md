## 签名与苹果公证 / Signing and Apple notarization

**此版本采用临时签名（ad hoc），未使用 Apple Developer ID 签名，未做苹果公证（Apple notarization）。**

**This version is ad hoc signed. It is not Apple Developer ID signed and has not been notarized by Apple.**

## 中文

PhotoStudio **1.2.7（构建 11）**，面向 **macOS 26.0 或更新版本、Apple Silicon（arm64）**。应用当前主要使用中文界面。

### 本次更新

- 全新浅色图标：蓝绿色六叶光圈、暖黄色中心，统一多尺寸圆角与透明边缘。
- 新增优化的 Release 构建与可重复打包脚本，提供 DMG 拖拽安装包、ZIP 和 SHA-256 校验文件。
- 保留目录树、完整 RAW 解码、缩略图总览和原生 Liquid Glass 界面。

### 下载与安装

| 文件 | 用途 |
| --- | --- |
| `PhotoStudio-1.2.7-macOS26-arm64.dmg` | 推荐安装包；打开后将 PhotoStudio 拖到“应用程序” |
| `PhotoStudio-1.2.7-macOS26-arm64.zip` | 解压后复制 `PhotoStudio.app` 到“应用程序” |
| `PhotoStudio-1.2.7-macOS26-arm64.sha256` | DMG 和 ZIP 的 SHA-256 校验值 |

运行无需 Xcode 或项目源码。下载校验文件及对应安装包至同一目录后，可执行 `shasum -a 256 -c PhotoStudio-1.2.7-macOS26-arm64.sha256 --ignore-missing` 检查已下载的包。

### 验证与支持范围

在 Apple Silicon、macOS 27.2 上完成 Release 构建、18 项核心测试、应用签名完整性、DMG、ZIP 及 SHA-256 校验。macOS 26 真机与 Intel 尚未验收；本次发布仅提供 arm64 应用。签名完整性校验不代表已获得 Apple Developer ID 签名或苹果公证。

## English

PhotoStudio **1.2.7 (build 11)** for **macOS 26.0 or later and Apple Silicon (arm64)**. The application currently uses a primarily Chinese interface.

### What's new

- A fresh light icon with a blue/turquoise six-blade aperture and warm yellow center, with consistent rounded corners and transparent edges at multiple sizes.
- Optimized Release builds and a repeatable packaging script, with a drag-install DMG, ZIP, and SHA-256 checksums.
- Retains folder-tree browsing, full RAW decoding, the thumbnail overview, and native Liquid Glass UI.

### Download and install

| File | Purpose |
| --- | --- |
| `PhotoStudio-1.2.7-macOS26-arm64.dmg` | Recommended installer; open it and drag PhotoStudio to Applications |
| `PhotoStudio-1.2.7-macOS26-arm64.zip` | Extract and copy `PhotoStudio.app` to Applications |
| `PhotoStudio-1.2.7-macOS26-arm64.sha256` | SHA-256 checksums for the DMG and ZIP |

Xcode and the project source are not required to run the app. Download the checksum file and chosen package into one directory, then verify downloaded packages with `shasum -a 256 -c PhotoStudio-1.2.7-macOS26-arm64.sha256 --ignore-missing`.

### Validation and support scope

The Release build, 18 core tests, application signature integrity, DMG, ZIP, and SHA-256 checks were verified on Apple Silicon running macOS 27.2. macOS 26 hardware and Intel execution have not been validated; this release provides an arm64 app only. Signature integrity verification does not mean Apple Developer ID signing or Apple notarization.
