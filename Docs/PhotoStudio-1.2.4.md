# PhotoStudio 1.2.4（构建 8）

2026-11-03。

- 修复收起总览时先切换成小缩略图、再向下移动的两段式观感。大网格与底部胶片条分别保持固定尺寸，收起过程只移动大面板，不再交叉淡出或改变面板高度。

- 主照片不参与布局和尺寸动画；继续保留底部上／下箭头、双击返回和 Esc。系统开启“减少动态效果”时直接切换。
