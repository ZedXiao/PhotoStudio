# 原生界面验收

2026-11-02，当前 Apple Silicon Mac，macOS 27.2；应用 1.0.1。

通过原生应用界面实际操作，并结合测试副本的文件存在性检查：

- 添加文件夹、打开单张 RAW，加载所在目录并自动开启 RAW 显示。
- 默认 RAW 隐藏、默认不递归；开启后独立列出 RAW，并可加入子目录照片。
- 左右方向键切图、首尾禁用、加减键缩放、100%、适应窗口、双击切换大小与拖动平移。
- RAW 显示完整解码的主图、相机型号、曝光参数和实际解码器。
- 竖拍 RAW 主图为 4000 × 6000，胶片条缩略图同向。
- 1.0.1 在此前会退出的 RAW 文件夹中连续切换 12 次，窗口保持正常，最终照片与选择一致。
- 删除确认默认不勾选 RAW；取消保留照片；未勾选只移走 JPEG，原目录中 RAW 仍存在；勾选同时移走 JPEG 与对应 RAW。
- RAW 隐藏时也能在删除框中找到同目录、同主文件名的配套文件。
- 删除后选择下一张；核心测试另覆盖末张、清空和部分失败。
- 损坏图片显示原因，仍可切换下一张。
- 重启后恢复已添加目录及各自的 RAW／子目录开关。
- 空目录显示提示；目录临时移动后显示重试、重选位置，恢复位置后刷新可继续读取。
- RAW 相机兼容窗口正确区分已验证样片、声明支持和本次失败记录。
- 测试完成后仅移除本次添加的测试目录列表记录，恢复欢迎界面；原始公开样片保留供复验。

完整解码、RAW 方向及缩略图的后台验证记录见 `raw-validation.json` 和 `portrait-validation.json`，所有条目均记录 `backgroundWorker: true`。18 份原始样片自动解码全部通过；强制 LibRaw 16 份通过，2 份 Nikon 高效率 NEF 需要系统解码。

触控板捏合使用 NSScrollView 原生能力，自动化未生成捏合手势；跨应用拖入文件采用系统 URL 拖放接口，未进行跨应用鼠标拖放验收。macOS 14 与 Intel 尚未进行真机运行测试。
