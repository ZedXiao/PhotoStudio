# PhotoStudio 1.2.2（构建 6）

2026-11-03。

缩略图总览与底部缩略图栏现在共用同一块玻璃面板。面板底边固定，展开时向上拉开，返回预览时沿同一路径向下收起，几何动画统一使用 280 ms ease-in-out。

去掉总览/底栏之间的 glassEffectID 切换、缩放/位移入退场与弹簧动画。预览保持在原视图中，面板收起时逐步让出预览区域，避免重新插入预览造成的跳变。内容使用短淡入淡出。

点击“返回预览”、顶部切换按钮、双击照片及 Esc 共用同一收起逻辑，重复关闭不会重新展开。收起后恢复预览焦点。总览期间停用主图缩放控件，避免操作隐藏的预览。开启系统“减少动态效果”时，区域高度直接切换，仅保留短淡入淡出。

构建与启动通过 `./script/build_and_run.sh --verify`。本次仅调整布局和动画，未修改扫描、解码及删除逻辑。

实际操作已验证顶部切换按钮、“返回预览”按钮、Esc 和双击选图均可收起，并恢复正常预览、选中照片和键盘焦点。总览期间主图缩放控件禁用，返回后恢复。
