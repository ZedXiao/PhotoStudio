# PhotoStudio 1.2.1（构建 5）

## 修复

- 侧栏由嵌套的动态 DisclosureGroup 子行改为系统 sidebar List 内稳定标识的目录行，保留层级缩进、展开/收起、独立目录选择、移除按钮和右键菜单。根行与子行分别使用固定内容高度，目录名限制单行。
- 加载状态使用每个目录自己的 loading 集合，在同一行右侧显示固定尺寸指示器；失败同样内联显示重试按钮。加载提示不再成为与目录标签互换的子行，避免异步数据更新时的重叠。
- 删除确认改为当前窗口内的单层 glassEffect 面板，去掉独立 NSPanel 及外侧留白，玻璃直接采样当前窗口中的照片。确认时底层控件禁用并从辅助功能内容中隐藏，面板取得键盘焦点。Esc 取消、回车确认，关闭后恢复预览焦点；减少动态效果时使用短淡入淡出。
- 保留 RAW 勾选记忆与废纸篓流程。只允许当前确认计划执行删除，避免关闭动画期间的过期操作。匹配 RAW 较多时列表可滚动，确保操作按钮留在窗口内。

## 验证

- `./script/test.sh`：18 项核心测试通过，0 失败。
- `./script/build_and_run.sh --verify`：构建、签名和启动检查通过。
- 实际窗口已检查目录行高度、缩进和选中显示；单层玻璃面板已检查照片透射和边缘，外层窗口边框不再存在。
- 已验证确认状态下方向键和缩放不改变底层照片，Esc 取消后恢复预览焦点。
- 在 QA 目录中已实际点击展开/收起及快捷移除按钮，目录行稳定更新；移除仅影响列表记录，磁盘目录仍保留。
- 已验证取消后减号缩放恢复（77% → 62%）、取消 RAW 勾选后的记忆，以及回车确认仅删除测试 JPEG、保留两个 RAW 并选中下一张。
- 删除确认操作只用独立 QA 偏好和生成样片验收；用户照片仅打开预览和取消确认，未执行删除。

最低系统要求仍为 macOS 26.0，Apple Silicon；构建验收环境为本机 macOS 27.2 与完整 Xcode 工具链。
