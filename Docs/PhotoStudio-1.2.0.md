# PhotoStudio 1.2.0（构建 4）

最低 macOS 26.0，Apple Silicon。2026-11-02 在本机 macOS 27.2、已安装的完整 Xcode 工具链上构建和操作验收。

## 本次行为

- “放大缩略图”将底部胶片条展开为大尺寸网格。单击选择；双击打开照片并返回大图与底部胶片条。提供“返回预览”和 Esc。展开/收起使用 280 ms、无回弹的可中断弹簧与系统玻璃面板变形；减少动态效果时改用短淡入淡出。
- 侧栏使用原生 List/DisclosureGroup，按需加载下一层目录。点击某层只扫描该目录自身，排除隐藏目录、包和符号链接，目录自然排序。不再将递归扫描作为应用浏览入口。旧“包含子文件夹”值迁移为根目录展开状态。
- RAW 可见性、展开状态按目录持久化；重启恢复上次所在的子目录。直接打开已添加根目录内的 RAW 会选择相应子目录并展开祖先、开启该层 RAW，不重复添加同一子目录为新根。
- 已添加根目录右侧有快捷移除叉号，右键菜单也保留。只移除保存记录，磁盘文件保持原位。子目录来自目录树，并未被添加为独立根记录。
- 缩略图的照片居中容器与右下角格式标签分离，修正竖图靠右。主预览在缩放后明确按两轴重新居中；100% 仍按屏幕 backingScaleFactor 计算实际像素。取消预览原生大面积焦点描边。
- 预览左右浮动玻璃箭头切换照片。适应窗口时，触控板横向滚动按 began/changed/ended/cancelled 生命周期识别；40 点阈值，过滤纵向意图、取消和 momentum 事件，同一手势最多切一张。放大后仍按原生滚动平移。
- 删除选项首次为关，之后持久化上次 RAW 联动勾选，即使取消或重启也保留。没有匹配 RAW 时显示未勾选且禁用，不覆盖已保存偏好。直接删除 RAW 只处理当前文件。
- 删除确认使用透明原生 NSPanel，以 beginSheet 保留窗口级模态；SwiftUI 负责内容、选项、进度和真实 glassEffect。此桥接是因为 [Apple 文档明确说明 macOS SwiftUI sheet 背景始终不透明](https://developer.apple.com/documentation/swiftui/view/presentationbackground(_:))。Esc 取消、默认确认按钮和部分失败后的系统提示均已操作验证。
- 验收时定位到系统书签创建可能阻塞主线程，已改为后台创建并校验目录身份后保存；新目录先进入列表并后台扫描。

## 验证记录

`./script/test.sh`：18 项通过，0 失败。新增测试覆盖目录层级不混合、自然排序、配对仍限定同目录、目录独立偏好与 RAW 删除选择重建后恢复、长手势只产生一次导航、惯性跨画布重建不导航、纵向/小幅/取消手势不导航。512 KiB 后台 RAW 栈回归和全部 EXIF 方向测试保持通过。

`./script/build_and_run.sh --verify`：构建、签名、启动及进程检查通过。最低部署目标由 Package.swift、脚本、Info.plist 与 Mach-O 一致声明为 26.0。

UI 使用 `--isolated` 偏好和 `.fixtures/ui-1.2` 的生成照片 / 公开 RAW 副本验收；未删除用户照片。
