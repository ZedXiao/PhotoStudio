# PhotoStudio 1.2.3（构建 7）

2026-11-03。

- 缩略图改为底部覆盖面板。主预览的布局不再依赖展开状态，原图大小、适应窗口比例和 100% 平移位置保持不变。
- 网格与胶片条保持挂载，网格内容使用固定尺寸；只改变覆盖层的裁切范围和位置，使用 240 ms 非弹簧缓动，避免逐帧适配和重新绘制完整照片。
- 展开控件移出文件信息栏与总览标题栏。底部面板上沿中央增加一体玻璃小凸起，上箭头展开、下箭头收起；保留双击与 Esc。
- 展开时直接移除预览左右箭头，避免夹在顶部或参与玻璃融合。确认覆盖层外的图片点击、缩放和拖动不被透明区域拦截。
- 空目录不显示展开凸起，减少动态效果设置下不移动面板区域，仅使用短淡入淡出。

## 验证

构建、签名和启动通过 `./script/build_and_run.sh --verify`。

实际操作验证：

- 适应窗口时展开前后均为 13%，没有缩成 1%。
- 100% 显示并拖动后，两轴滚动位置为 0.4656488549618321、0.4915994623655914。展开、收起后两值完全一致，缩放仍为 100%。
- 底部凸起的上箭头、展开后的下箭头均清晰可见；文件信息栏和总览标题栏不再提供重复返回按钮。
- 展开后顶部无残留左右导航按钮，单层玻璃直接覆盖固定照片预览。
- 点击箭头、双击照片和 Esc 均能收起并恢复预览焦点。

本次未修改照片扫描、RAW 解码或废纸篓逻辑。最低系统要求仍为 macOS 26.0，Apple Silicon。
